# Project overview

AURA-5, “the fifth crew member,” is NOVARAIA-X's astronaut-health support prototype. The proposed role is to organize observations, support daily routines and demonstrate structured follow-up when communication is delayed.

The implemented scope is a bilingual web demonstration with synthetic mission records, manual check-ins, rule-based urgency, a reaction-time task, sleep/stress support, crew planning suggestions and simulated communication.

It does not diagnose disease, prescribe medication, integrate live sensors, contact mission control or provide validated clinical decisions.

Future work includes flight-surgeon review, analog usability studies, sensor integration, evaluation against validated protocols, and stronger privacy and access controls. None of these future steps is claimed as completed.

The team has stated that separate technical model documentation is already complete. That document was not supplied for incorporation into this repository; these files describe the shipped prototype and do not replace or claim to review it.
