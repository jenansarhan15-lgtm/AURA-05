# AI methodology and disclosure

## Implemented decision method

This repository implements explicit Python rules, descriptive comparisons and thresholds. It does not contain a trained machine-learning model, model checkpoints, an LLM API integration or a measured clinical-accuracy result.

The browser attention task is inspired by PVT-B research; its custom implementation and thresholds have not been clinically validated. The first two valid task sessions form a personal reference when available; otherwise a prototype reference is used.
