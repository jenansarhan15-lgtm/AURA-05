## Create the repository manually

1. Unzip this package.
2. Create a new GitHub repository, suggested name `AURA-5`, owned by the team account.
3. Choose **Public** only after completing the provenance and privacy checks above.
4. Upload the contents of the `AURA-5` folder so `README.md` is at the repository root.
5. Ensure hidden `.gitignore` is included. Review the file list before publishing.
6. Open the repository while signed out to confirm reviewers can access it.
